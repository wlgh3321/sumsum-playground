# 셈셈 놀이터 · SumSum Playground

덧셈, 뺄셈, 곱셈, 나눗셈을 6가지 게임으로 연습하는 웹사이트예요.
A web game for practicing addition, subtraction, multiplication and division.

- 문제 비 / Falling Problems
- 1분 도전 / Minute Challenge
- 60문제 타임어택 / 60-Question Race
- 풍선 팡팡 / Balloon Pop
- 시간 버티기 / Beat the Clock
- 참 거짓 스피드 / True or False
